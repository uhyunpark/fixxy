fixxy Spectral — 두 가지 스킨

같은 레이아웃 위에 두 개의 시각 언어를 얹었다. 위는 우리 플러그인 패밀리의 기존 언어인 Family Dark(FixxyLookAndFeel: 어둡고 평평한 크롬, 쿨 블루=신호 / 앰버=동작, 모노스페이스 수치), 아래는 design-reference.md의 Family Light(크림 종이 캔버스, 그림자 대신 헤어라인 인셋, 엠버 오렌지 액션 액센트)다. 던지는 질문은 하나다: 이 신규 플러그인에서 라이트 언어를 데뷔시킬 것인가 — 아니면 계측기다움(다크)을 지킬 것인가.

폰트는 자체 포함을 위해 외부 로딩 없이 시스템 스택으로 근사했다: Inter → 시스템 산세리프, Family 디스플레이(Druk Wide/GT America Compressed) → Arial Narrow 계열 압축 볼드, 다크 수치 모노스페이스 → 시스템 모노. 라이트 변형의 수치는 모노 대신 tabular-nums로 정렬한다.

설계 결정 3가지 — Dark

  1. 색 = 의미 규칙 계승. 스펙트럼/응답 곡선은 쿨(#8fd0ff 신호), 리덕션 리본과 경계 핸들은 앰버(#e0783c 동작)로만 칠했다. soothe의 임의적 빨강/초록 핸들 대신, "지금 처리 중"을 앰버 하나로 통일해 패밀리 규칙(쿨=신호/웜=동작)을 지켰다.
  2. 계측기다운 수치. 모든 값 칩(5.0, 100 %, 0.0 dB)과 우측 dB 눈금은 모노스페이스로 두어 소수점이 정렬되게 했다 — FixxyLookAndFeel의 의도적 시그니처.
  3. 평평한 크롬, 데이터만 발색. 그라데이션·그림자 없이 well은 인셋 1px 헤어라인으로만 구분하고, 배경/그리드/틱은 전부 모노크롬 그레이로 눌러 신호와 액센트가 유일한 색이 되게 했다.

설계 결정 3가지 — Light

  1. 종이용 데이터 색을 새로 설계. 크림 캔버스에서 라이트 블루(#8fd0ff)는 대비가 죽어 신호를 #0b61c4(딥 애저)로, 레퍼런스는 #6d82a6(뮤트 스틸)로 낮췄다. 응답 곡선은 흰색 대신 #1b1b1b 잉크 — 종이 위에서 가장 대비 높은 마크가 되어야 하므로.
  2. 액션 슬롯은 엠버 오렌지 고정. 리덕션 리본과 경계 핸들·인디케이터 점은 #ff3e00 하나로 통일했다. design-reference의 액션 색과 패밀리의 "웜=동작" 규칙이 정확히 겹치는 지점이라 그대로 승계했다.
  3. 그림자 없는 종이 질감. well은 순백(#ffffff) + #f2f0ed 인셋 헤어라인, 나머지 표면은 크림/스톤 톤차로만 구분(0.04 알파 이상 그림자 금지). 모노스페이스 대신 tabular-nums로 수치를 정렬해 라이트 언어를 유지하면서 계측기 정렬은 지켰다.
